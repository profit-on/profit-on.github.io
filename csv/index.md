# Импорт и экспорт аккаунтов CSV в лаунчере PROFITON

Примечание:

Формат CSV-файла для импорта и экспорта аккаунтов Steam в лаунчере PROFITON.

* * *

## Пример аккаунта

**1 строка → 1 аккаунт.** Каждая строка CSV описывает один аккаунт Steam.

```
"70000000000000005","acc5","http://login:password@proxy.com:1234","SteamPassword","MarketApiKey",1
```

| Позиция | Параметр |
| --- | --- |
| 1 | Steam ID |
| 2 | Alias |
| 3 | Proxy |
| 4 | Password |
| 5 | Market CS:GO API Key |
| 6 | SSA ID |

Предупреждение:

**Все параметры должны быть в кавычках (кроме SSA ID)!**

**Обязательны все шесть позиций в строке.** Password и Market CS:GO API Key могут быть пустыми: если значение не используется, укажите пустые кавычки `""`.

* * *

## Steam ID

Уникальный идентификатор аккаунта Steam. Должен **начинаться с 7** и **иметь длину 17 символов**.

* * *

## Alias

Внутреннее название аккаунта в лаунчере. **Минимальная длина - 3 символа**.

* * *

## Proxy

Индивидуальный прокси аккаунта. Должен подходить под **один из шаблонов**:

-   `http://login:password@proxy.com:1234`
-   `http://login:password@11.22.33.44:1234`
-   `socks5://login:password@proxy.com:1234`
-   `socks5://login:password@11.22.33.44:1234`

Как выбрать прокси, описано в разделе [_**Прокси**_](/knowledge-base#%D0%BF%D1%80%D0%BE%D0%BA%D1%81%D0%B8) базы знаний.

* * *

## Password

Пароль от аккаунта Steam. Минимальной длины нет, максимальная - **50 символов**. Если пароль не указывается, вставьте пустые кавычки: `""`.

* * *

## Market CS:GO API Key

API-ключ Market CS:GO. Минимальной длины нет, максимальная - **50 символов**. Если ключ не указывается, вставьте пустые кавычки: `""`.

* * *

## SSA ID

Статус аккаунта и привязка к экземпляру SSA (Steam server-side authenticator). Единственный параметр **без кавычек**.

**Если у вас 1 SSA:**

-   `0` → аккаунт выключен
-   `1` → аккаунт включён

Другие цифры недопустимы, аккаунт не будет принят системой.

**Если у вас 2 и более SSA:**

-   `0` → аккаунт выключен
-   `1` → аккаунт включён и привязан к SSA 1
-   `2` → аккаунт включён и привязан к SSA 2
-   и так далее

Допустимо использовать только те цифры, сколько у вас имеется SSA.

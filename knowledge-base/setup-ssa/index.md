# Настройка Steam server-side authenticator

## Теоретические основы

Steam server-side authenticator (SSA) — альтернатива публичной версии SDA, используемая для автоматизации процессов: получение Steam Guard, автоматическое принятие подарочных трейдов, сделок на Торговой площадке Steam и передачи предметов на Market CS:GO.

## Практическая настройка

Примечание:

**При необходимости вы можете вернуться к исходной конфигурации. Для этого в окне редактирования конфигурации нажмите правой кнопкой мыши и выберите пункт «Вернуть шаблонную конфигурацию».**

Примечание:

В конфигурации используются два типа прокси. **Индивидуальный прокси** — выделенный IP-адрес, через который аккаунт Steam выполняет всю торговую работу (листинги, ордера на покупку, трейды). Оптимально один аккаунт на один IP, если аккаунтов много — допустимо до 2-3 на один адрес, но чем больше аккаунтов делят IP, тем выше суммарная нагрузка запросами и риск блокировки адреса со стороны Steam (ошибка 429, слишком много запросов). **Прокси-пул** (Webshare) — отдельный пул IP-адресов, который софты используют для многопоточного парсинга цен по всем торговым площадкам, работает полностью независимо от аккаунтов Steam и не расходует их лимиты запросов. Как выбрать и проверить прокси, описано в разделе [_**Прокси**_](/knowledge-base#%D0%BF%D1%80%D0%BE%D0%BA%D1%81%D0%B8) базы знаний.

**Параметры, требующие заполнения**

```
# Токен вашего Телеграм-бота (Обязательное поле).
  token:
```

“Токен Telegram-бота” - уникальный ключ, который выдается при создании бота. Создайте бота через _@BotFather_ и скопируйте токен.

-   Откройте мессенджер Telegram на своем устройстве (смартфон, планшет или компьютер).
-   В поисковой строке Telegram найдите аккаунт _@BotFather ([https://t.me/BotFather](https://t.me/BotFather))_. Он является официальным сервисом для создания и настройки ботов.
-   Откройте диалог с _@BotFather_ и начните общение с ним, нажав кнопку _“Start”_ или отправив команду _/start_.
-   Для создания нового бота отправьте команду _/newbot_.
-   Следуйте инструкциям _@BotFather_:
    -   Введите имя вашего бота. Это отображаемое имя, которое видят пользователи.
    -   Введите уникальное имя пользователя для бота. Оно должно заканчиваться на «_bot_» или «_\_bot_» и быть уникальным в рамках всей платформы Telegram.
-   Если все введенные данные корректны, _@BotFather_ создаст вашего бота и предоставит вам его токен доступа. Этот токен является ключом для управления ботом и обязателен для настройки и использования бота. Сохраните его в безопасном месте.

Предупреждение:

**Для каждого софта обязательно создайте отдельного Telegram-бота. Нарушение этого правила приведёт к некорректной работе и ошибкам.**

```
# Ваш чат ID в Телеграме (Обязательное поле).
  chat_id:
```

_**“Chat ID”**_ - идентификатор вашего чата в Телеграме.

-   Откройте мессенджер Telegram на своем устройстве (смартфон, планшет или компьютер).
-   В поисковой строке Telegram найдите аккаунт _@getmyid\_bot ([https://t.me/getmyid\_bot](https://t.me/getmyid_bot))_.
-   Откройте диалог с _@getmyid\_bot_ и начните общение с ним, нажав кнопку _“Start”_ или отправив команду _/start_.
-   Если все сделано корректно, бот предоставит ваш Chat ID.

```
# Язык всех сообщений и кнопок Телеграм-бота (ru - русский, en - английский).
  language: ru
```

**«Language»** задаёт язык всех сообщений и кнопок Telegram-бота. Укажите _ru_ для русского языка или _en_ для английского.

```
Status (Enable/Disable):
```

_**”Status (Enable/Disable)”**_ - параметр, определяющий активность аккаунта Steam в Steam server-side authenticator.

-   **Enable:** Активирует аккаунт, позволяя софту обновлять сессию, получать коды Steam Guard и выполнять другие необходимые действия.
-   **Disable:** Отключает аккаунт, приостанавливая его работу в софте. Аккаунт будет находиться в режиме ожидания до тех пор, пока вы не активируете его снова, изменив статус на “Enable”.

Для изменения статуса аккаунта выберите нужное значение в соответствующем поле.

```
Alias:
```

_**”Alias”**_ - подпись аккаунта в софте. Именно это название будет отображаться в уведомлениях Telegram-бота при управлении софтом через Telegram.

```
steamid:
```

“_**SteamID**_” - уникальный идентификатор вашего аккаунта Steam.

-   Для получения SteamID откройте файл MaFile, связанный с вашим аккаунтом, с помощью текстового редактора (например, блокнота). Внутри файла найдите параметр SteamID - это и будет вашим идентификатором.

```
proxy:
```

_“Proxy (HTTP)”_ - прокси-сервер, используемый для обеспечения анонимности и безопасности ваших аккаунтов при работе с софтом.

-   Вы можете приобрести HTTP-прокси на сервисе, таком как Proxyline.net (это не реклама, а пример возможного сервиса).
-   Убедитесь, что выбираете именно HTTP-прокси, поскольку прокси типа SOCKS5 не подойдут для работы с этим софтом.
-   Вам нужно будет указать прокси в формате: `http://ЛОГИН:ПАРОЛЬ@IP-адрес:ПОРТ` при заполнении конфигурации.

```
password:

ПРИМЕР:
password: Nagibator2010#@!
```

“_**Password**_” — ваш пароль для доступа к аккаунту Steam.

```
market_csgo_api_key:
```

_**“API-ключ Market CS:GO”**_ - это уникальный идентификатор, позволяющий софту работать с вашим аккаунтом на площадке Market CS:GO.

Создание ключа, настройка ссылки для обмена и добавление ключа в PROFITON Launcher описаны в отдельном руководстве: [_**Получение API-ключа Market CS:GO**_](/knowledge-base/market-csgo-api-key).

**Пример заполнения конфигурации и добавления аккаунтов**

### 1) Пример корректного заполнения конфигурации SSA.

```
telegram:
# Токен вашего Телеграм-бота (Обязательное поле).
  token: 6336844150:ABY2Jonpe2JTAEYUJtKeBNyO3xbKw-FFAt0
# Ваш чат ID в Телеграме (Обязательное поле).
  chat_id: 2365344527
# Язык всех сообщений и кнопок Телеграм-бота (ru - русский, en - английский).
  language: ru

# Автоматическое принятие подарочных трейдов через API Steam (true/false).
check_gifttrades: true
# Интервал проверки новых подарочных трейдов через API Steam (например, 30s, 1m, 5m).
check_gifttrades_interval: 1m

# Автоматическое принятие подарочных трейдов через Market CS:GO (true/false).
check_gifttrades_market: true
# Интервал проверки новых подарочных трейдов через Market CS:GO (например, 30s, 1m, 5m).
check_gifttrades_market_interval: 1m

# Включение/отключение проверки новых подтверждений Steam (true/false).
check_confirmations: true
# Интервал проверки подтверждений. При автоподтверждении трейдов фактически используется 1m.
check_confirmations_interval: 1m

# Автоматическое подтверждение трейдов в мобильном приложении Steam (true/false).
autoconfirm_trades: true
# Автоматическое подтверждение выставления лотов на продажу и покупок на торговой площадке Steam (true/false).
autoconfirm_market_transactions: true
```

### Инструкция по использованию

1.  _**Откройте лаунчер PROFITON.**_
2.  _**Выберите Steam server-side authenticator из списка софтов.**_
3.  _**Конфигурация SSA (Подробное описание каждого параметра вы найдёте в разделе `Параметры, требующие заполнения`):**_
    -   Перейдите в раздел конфигурации SSA.
    -   Заполните следующие параметры:
        -   _**Token**_ (токен Telegram-бота)
        -   _**Chat ID**_ (идентификатор вашего чата в Telegram)
        -   _**language**_ (язык сообщений и кнопок Telegram-бота)
    -   Сохраните конфигурацию и при необходимости перезапустите SSA.
4.  _**Добавление и управление аккаунтами Steam (Подробное описание каждого параметра вы найдёте в разделе `Параметры, требующие заполнения`):**_
    -   Перейдите в раздел “Аккаунты”.
    -   Заполните следующие параметры:
        -   _**SteamID**_
        -   _**Alias**_
        -   _**Proxy (HTTP)**_
        -   _**Steam Password**_
        -   _**Market CS:GO API Key**_
        -   _**Status**_
        -   _**MaFile**_
    -   Управляйте аккаунтами:
        -   **Добавление/удаление (_Add account/Delete account_)**
        -   **Редактирование параметров (двойной клик)**
        -   **Удаление MaFile (двойной клик)**
        -   **Включение/отключение (_Status_)**
5.  _**Запуск и активация:**_
    -   Запустите привязанный Telegram-бот и активируйте его командой `/start`.
    -   Запустите SSA в лаунчере PROFITON или через Telegram-бота.
    -   Дождитесь подтверждения подключения аккаунтов (`✅ #Alias: Account connected`).

**Кнопки Telegram-бота**

-   `guard` Генерирует коды Steam Guard для двухфакторной аутентификации.
    -   _**При первом добавлении аккаунта в SSA, если у вас ещё нет API-ключа Market CS:GO, вы можете оставить это поле пустым. Это позволит SSA подключиться через прокси и получить код Steam Guard для авторизации, необходимой для последующего создания API-ключа на сайте Market CS:GO.**_
    -   _**Не используйте публичный SDA для получения первого кода Steam Guard, так как это может привести к блокировке аккаунта системой антифрода Steam.**_
-   `confirmations` Предоставляет список подтверждений аккаунта, необходимых для различных действий, таких как создание API-ключа, смена пароля Steam и т.д.

**Когда нужен перезапуск**

-   **Изменили конфигурацию** → перезапустите SSA.
-   **Добавили, удалили или изменили аккаунт** → перезапустите **все** софты с этим аккаунтом.
-   **Сменили индивидуальный прокси** → обновите в SSA, перезапустите **все** софты с этим аккаунтом. Например, если не перезапустить Steam Market селлер и Market CS:GO брокер, они продолжат работать через старый IP.
-   **Сменили прокси-пул** (Webshare) → обновите в софтах, где он указан (например, Steam Market селлер, Market CS:GO брокер), и перезапустите их. В SSA прокси-пул не настраивается.
-   **Сменили пароль Steam или API-ключ Market CS:GO** → перезапустите все софты с этим аккаунтом.

Примечание:

Если открыли конфигурацию, ничего не изменили — перезапуск не нужен.
